# Changelog

## 0.1.0

Initial scoped source port of vnc-rs 0.5.3: RFB negotiation, VNC authentication, true-color Raw/CopyRect/TRLE, cursor/desktop resizing, input serialization and bounded sans-I/O sessions. Includes three local TCP examples and differential validation. Not a complete vnc-rs feature replacement; compressed encodings and TLS are excluded.
